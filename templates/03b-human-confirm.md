# 03b Human confirm (G3 anti-forge)

Paste **exact** user (and PM) messages. AI must not invent these lines.

## User confirm

```
CONFIRM G3: <Ticket_ID> <Human_Name> <YYYY-MM-DD>
```

## PM confirm (required if Risk P0)

```
CONFIRM G3-PM: <Ticket_ID> <PM_Name> <YYYY-MM-DD>
```

## Meta

- **Source:** user-message
- **Recorded by (AI/tool):** [assistant name]
- **Recorded at:** [YYYY-MM-DD]

**Forbidden names in CONFIRM lines:** AI, ChatGPT, Claude, Copilot, Cursor, Assistant, Bot
