# Plugin: dev-workflow

Version `0.1.0`. Goal: force clear requirements before code.

Docs: [README.en.md](./README.en.md) · [README.vi.md](./README.vi.md) · [README.ja.md](./README.ja.md) · [STRUCTURE.md](./STRUCTURE.md) · [MARKETPLACE.md](./MARKETPLACE.md)

Install (quick):
- Claude Code: `/plugin marketplace add <path>` → `/plugin install dev-workflow@dev-workflow-marketplace`
- Cursor/Codex/local: `bash install.sh`
- Antigravity: `bash hosts/antigravity/rebuild.sh` then `agy plugin install ./hosts/antigravity`

Flow: `learning → coaching → spec → conflict → plan → build → confirm → /dev-workflow:check → ship`.
